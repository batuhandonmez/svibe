# Svibe Design Direction

## Goal

Svibe should feel like a premium audio-first social product, not a generic
AI-generated demo. The interface should make the user feel that each voice is
an intentional signal.

## Product Rules Reflected In UI

- No rooms. The main surface is discovery.
- Discovery shows one voice at a time.
- DM belongs in the top right of the feed.
- Cast is a deliberate action, not a generic bottom-tab item.
- The first three seconds are a listening gate.
- Golden Voice and Cast are rituals, but every motion gesture has a manual
  fallback.

## Visual Language

- Neutral surfaces carry most of the UI.
- Accents are used as signals: ember for cast/golden moments, teal for active
  actions, acid only as a rare high-energy marker.
- Avoid Spotify green, purple-blue gradients, large decorative blobs, and
  oversized rounded cards.
- Cards use sharper corners so the product feels more editorial and less like
  a template.
- Light and dark mode should share the same hierarchy and spacing.
