# Demo audio

Drop natural WAV recordings here using these names:

- `nova-golden-voice.wav`
- `echo-morning-note.wav`
- `mira-city-walk.wav`
- `atlas-short-thought.wav`
- `demo-user-archive.wav`

`seed_local_demo.py` copies matching files into the local demo. Missing files
fall back to generated tones, so the presentation setup still starts.
